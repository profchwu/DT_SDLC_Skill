# Integrated quality gates

| Gate | Minimum evidence |
| --- | --- |
| DT problem gate | Users, evidence, problem, scope, success measures |
| DT solution gate | Compared options, prototype, test result, MVP approval |
| Requirements gate | Testable functional and non-functional requirements; inputs, processing, outputs, delivery context, and acceptance examples are explicit or intentionally deferred |
| Design gate | Architecture, contracts, technology rationale, visual and accessibility criteria when applicable, security and safety boundaries, deployment model, risks, test strategy |
| Build gate | Working increment, source changes, local verification |
| Verification gate | Required tests and acceptance evidence |
| Release gate | Installation, secret configuration, migration, rollback, monitoring, incident ownership, known limitations |
| Final acceptance | User approval and traceability closure |
